# Archived Results

This directory contains experimental artifacts, run outputs, and logs preserved from earlier development phases and preliminary diagnostic evaluations prior to running the standardized 30-seed full research experiments.

Preserved items:
- `incidents.csv` and `incidents.json`: Preliminary incident logs generated during initial Phase 5/8 testing.
- Earlier runs of diagnostic evaluations (e.g. single-scenario audits like seed 44).

These files are retained for auditability and history, per the project ground rules ("Never delete earlier experimental records").
