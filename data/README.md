# Dataset Information: Indian E-Commerce Orders

## Provenance
- **Source repository:** [mvinayak96/ecommerce-sales-analysis](https://github.com/mvinayak96/ecommerce-sales-analysis)
- **Primary file:** `E-Commerce.csv`
- **Origin:** Great Learning DSBA (Data Science and Business Analytics) program project.
- **Licence note:** Course project dataset with no stated commercial license. Used strictly for academic evaluation and research benchmarking.

## Download Instructions
The raw CSV file should be placed in this folder as `data/E-Commerce.csv`.

To download it directly from GitHub:
```bash
curl -L "https://raw.githubusercontent.com/mvinayak96/ecommerce-sales-analysis/main/E-Commerce.csv" -o data/E-Commerce.csv
```
Note: Per repository `.gitignore`, raw CSV files must not be committed to GitHub.
